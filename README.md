# Skardu Road Obstacle Detection

## Project Overview
An AI-powered road object detection system
designed for mountain roads in Skardu.

## Technologies Used
- Python
- YOLOv11
- Ultralytics
- Roboflow
- FastAPI
- Streamlit
- OpenCV

## Detection Classes
1. Rock
2. Landslide
3. Road_Blockage

## Features
- Upload road images
- AI-based object detection
- Bounding box visualization
- Detection confidence scores
- Total detected objects

## Model
Custom-trained YOLOv11 model.

## Project Structure
- backend.py
- frontend.py
- download_dataset.py
- runs/detect/train/weights/best.pt
